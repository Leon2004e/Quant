ZIEL

Verwende immer denselben visuellen Stil.

Der Inhalt der Software ist irrelevant.

Es geht ausschließlich um das Design-System.

Die Software kann alles sein:

- Datenplattform
- IDE
- Dashboard
- Analytics Tool
- Research Tool
- Management Tool
- Trading Tool
- Builder Tool

STYLE PHILOSOPHY

Form folgt Funktion.

Maximale Klarheit.
Maximale Übersicht.
Maximale Informationsdichte.

Jedes Element muss einen Zweck erfüllen.

Keine Dekoration.

Keine Marketing-Optik.

Keine SaaS-Optik.

Keine App-Optik.

Keine Mobile-Optik.

Die Software soll wirken wie ein professionelles Desktop-Werkzeug.

REFERENZEN

- VS Code
- JetBrains
- Obsidian
- Unreal Engine Editor
- Notion Desktop
- Figma Desktop

NICHT

- Bloomberg
- TradingView
- Stripe
- Linear
- Moderne Startup Dashboards

LAYOUT PHILOSOPHIE

Große Arbeitsfläche.

Navigation ist sekundär.

Content ist primär.

Panels sind Werkzeuge.

Der Nutzer arbeitet im Workspace.

Nicht im Dashboard.

VISUELLE REGELN

- Dunkles Theme
- Klare Kanten
- Sehr wenige Farben
- Dezente Borders
- Viel Luft
- Gute Hierarchie
- Keine Effekte

VERBOTEN

- Glows
- Glassmorphism
- Neons
- Schatten
- Gradients
- Riesige KPI Karten
- Bunte Flächen
- Marketing Banner

KOMPONENTEN

Alle Komponenten sollen aussehen als wären sie Teil derselben Plattform.

Buttons
Panels
Tabellen
Bäume
Explorer
Charts
Editoren
Formulare

verwenden dieselbe Designsprache.

WORKSPACE

Der Workspace ist immer das wichtigste Element.

Mindestens 70-80% der visuellen Aufmerksamkeit muss auf dem Arbeitsbereich liegen.

BEISPIELBILD

Das beigefügte Bild dient ausschließlich als Stilreferenz.

Nicht den Inhalt kopieren.

Nicht die Funktionen kopieren.

Nicht das Layout kopieren.

Nur die visuelle Sprache übernehmen:

- Proportionen
- Dichte
- Farben
- Hierarchie
- Professionalität
- Workspace-Fokus
