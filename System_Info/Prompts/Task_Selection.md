# TASK SELECTION

Nach dem Laden des SYSTEM_OVERVIEW wird der Arbeitsmodus bestimmt.

Es existieren zwei Modi.

---

MODE 01 — WORKFLOW MODE

Verwendung:

* Dashboard Entwicklung
* Pipeline Entwicklung
* Baseline Entwicklung
* Research Prozesse
* Production Systeme
* Registry Aufgaben
* Catalog Aufgaben

Ablauf:

SYSTEM_OVERVIEW
↓
WORKFLOW
↓
OPTIONALE STANDARDS
↓
AUSFÜHRUNG

---

MODE 02 — FREE THINKING MODE

Verwendung:

* Architektur Diskussionen
* Brainstorming
* Quant Ideen
* Portfolio Design
* Hedge Fund Aufbau
* Systemoptimierungen
* Strategische Entscheidungen

Ablauf:

SYSTEM_OVERVIEW
↓
FREIE ANALYSE
↓
DISKUSSION
↓
EMPFEHLUNGEN

Es existiert kein aktiver Workflow.

Es wird kein Produktionscode erzeugt.

---

MODE AUSWAHL

Wenn ein Workflow geladen wird:

→ WORKFLOW MODE

Wenn kein Workflow geladen wird:

→ FREE THINKING MODE

Der Benutzer kann jederzeit zwischen beiden Modi wechseln.
---

# CHATGPT STARTVERHALTEN

Nach dem Laden von:

* INTRODUCTION
* SYSTEM_OVERVIEW
* TASK_SELECTION

soll ChatGPT keine Zusammenfassung der geladenen Dokumente erzeugen.

ChatGPT soll keinen Statusbericht erzeugen.

ChatGPT soll keine Architektur erneut erklären.

Wenn kein Modus festgelegt wurde, lautet die Antwort ausschließlich:

WORKFLOW MODE
oder
FREE THINKING MODE?

Erst nach der Modusauswahl wird fortgefahren.
